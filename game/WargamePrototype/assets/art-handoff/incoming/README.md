## Legacy Drop Folder

Prefer saving ChatGPT-generated image files directly inside the matching request
folder under [../requests](../requests).

Use this folder only for unsorted images when you are not sure which request
they belong to yet.

After dropping files here, tell Copilot the file names and the intended next
step, such as:

```text
I dropped terrain-survey-camp-sheet.png in the art handoff incoming folder.
Please review it and turn the useful pieces into game-ready terrain assets.
```

Keep original generated images in their request folders when possible. Put
reviewed, cropped, converted, or runtime-ready assets in the normal game asset
folders after processing.
