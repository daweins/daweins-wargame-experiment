## Prompt

Copy this into ChatGPT image generation:

```text
Create a small tactical game UI icon concept sheet.

Icons to include: move, attack, wait, capture, repair, supply, rescue, end turn,
terrain defense, objective marker, HQ danger, scout rescued.

Requirements: simple symbolic shapes, readable at small size, consistent stroke
weight, compatible with pixel-art UI, and distinct from unit sprites and terrain.

Style: crisp 16-bit-era pixel UI icons for a grounded near-future sci-fi tactical
wargame, limited palette, clean outlines, no gradients that would blur at small
size, no photorealism.
```
