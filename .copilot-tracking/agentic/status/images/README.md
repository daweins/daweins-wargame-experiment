## Purpose

Store public-safe screenshots and image evidence linked by development status
reports. Use this folder for visual, UI, Steam Deck, readability, and generated
asset evidence when the image is useful to preserve in the repo.

## Safety Rules

* Include only screenshots or images that are safe for a public repository.
* Do not include images that reveal secrets, private local paths, private
  hostnames, private device details, credentialed tool output, raw logs, or
  sensitive machine state.
* Prefer descriptive filename-safe timestamps or short scenario names.
* Link images from reports with relative Markdown image syntax and useful alt
  text.
